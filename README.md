# Data-Science-Portfolio
A case study of forecasting and optimization problems using Walmart's M5 dataset.

00. Sourcing, wrangling, staging
01. Demand forecasting (Naive, ARIMA, LightGBM, XGBoost)
02. Inventory simulation + analysis
03. Revenue optimization + price elasticity (log-demand, GLM, calculus)
04. Experimentation (Simulation, AB testing, DiD)
05. Deep learning (LSTM) + data mining (k-means, PCA, factor analysis)
